# NUT Studio v1.1.5

A lightweight Windows configurator for the WEIKAV NUT65 CU keyboard.

## 下载

在本仓库的 **Releases → 最新版本 → Assets** 下载 `NUT-Studio-Win11-v1.1.5.zip`，解压后运行 `NUT-Studio.exe`；也可下载单文件 `NUT-Studio-v1.1.5.exe`。GitHub 自动生成的 Source code 为源码包。

当前 EXE 未进行代码签名，下载校验值见 Release 的 `SHA256SUMS.txt`。运行依赖系统 .NET Framework 4.8 和 Edge。

MIT 许可证见 [LICENSE](LICENSE)；第三方来源与许可见 [第三方声明](docs/THIRD-PARTY-NOTICES.md)。

## 简介

适用于 Windows 11 x64 的 WEIKAV（维咖）NUT65 CU 配置工具。支持可视化改键、前灯带调节、CU 固件扩展设置、本机方案和按键测试。深色界面与铜色点缀，本机运行，无需账户。

**开源致谢：NUT Studio 的 NUT65 CU 适配使用并参考了 [打包还是带走（packOrTake）的 weika-nut65-firmware](https://gitee.com/packOrTake/weika-nut65-firmware) 开源项目。感谢原作者的贡献。** 具体采用 CU V37 的配置定义、灯效名称与编号、自定义菜单和专用键码语义，参考提交为 `8427691`。发布包保留原作者版权声明及 MIT 许可全文；完整中文说明见 [开源来源与致谢](docs/ACKNOWLEDGEMENTS.md)。

**CU 的主要发光部位是前方 80 颗灯珠的灯带，另有 8 颗状态指示灯。**

## 启动与更新

1. 在旧版中选择 **使用帮助 → 退出软件**，再关闭 VIA、OpenRGB、SignalRGB 等其他控制软件。
2. 将新版 ZIP 解压到可写文件夹，双击 **NUT-Studio.exe**。
3. 用 USB 数据线连接键盘并切换到有线模式。
4. 使用第三方固件时，选择 **VIA** RGB 控制协议：固件默认通过 **Fn + Y** 循环切换，红色反馈表示 VIA。若已改键，使用你分配的“RGB 控制协议切换”键。
5. 点击 **连接键盘 → Windows 直接连接**，等待读取。灯光与设备功能调整后实时生效，停止操作约 1 秒后自动保存；键位修改点击 **应用键位 → 应用并保存**。

也可直接使用单文件 `NUT-Studio-v1.1.5.exe`。界面和键位种子均已内置。不要覆盖仍在运行的旧 EXE。

旧版的本机方案保存在程序旁的 `data/profiles.json`，恢复快照在 `data/backups/`。在新文件夹运行时，可自行复制原有 `data` 文件夹，或从旧版导出 JSON 再导入。**没有固件标记的旧版灯效编号不会自动套用到 CU 固件；这类方案会载入键位，请重新选择灯效。** 原始 `NUT65 CU.json` 保持不变。

要求：Windows 11 x64、系统自带的 .NET Framework 4.8 和 Microsoft Edge。不需要管理员权限、SDK、Node.js 或另外安装 USB 驱动。Edge 以独立窗口显示本机界面。直接连接失败可尝试连接窗口的 **浏览器 USB 连接**（Edge / Chrome 的 WebHID）。

## 实时控制与本次修复

v1.1.4 新增 **“前灯带开 / 关（软件联动）”**：在改键页“灯光快捷键”中重新分配该选项并应用。按一次以 CU 的 22 号关闭状态熄灭前灯带，再按一次恢复关闭前的灯效和模式；关闭按钮也改用 22，保留状态指示灯。**需要 Windows 直接连接和 NUT Studio 窗口运行，可以最小化；关闭窗口、退出软件或断开 USB 后联动停止。** 该选项把 F24 专用于灯带触发，启用后所有 F24 输入会被系统热键接收。固件原有 `RGB_TOG` 与 `RL_OFF` 保留，不自动替换已有键位。详见 [docs/SHORTCUT-AND-EFFECTS.md](docs/SHORTCUT-AND-EFFECTS.md)。

灯效卡片现在显示对应的英文原名和编号，往返扫描、双向扫描等名称更明确；重写 CU 预览，区分色相变化、亮度呼吸、扫描、频闪、霓虹、心跳和烟花。预览仍为示意，不保证与固件逐帧一致。上游手册与 VIA 定义对 12 / 13 号存在冲突，本版保留 VIA 的发送编号，没有按未经确认的猜测互换它们。游戏模式 `KC_GME` 的实际行为未公开说明，界面已补充提示，不宣称性能提升或等同于 Win 键锁定。

v1.1.3 兼容实体快捷键关闭灯带后的设备值 **22（0x16）**。该值未出现在 CU 的 VIA 菜单里，但实物日志确认关灯后会回读它。软件现在能读取、备份和恢复该状态；界面显示为“灯带已关闭 · 实体快捷键”。**关灯后可直接选择“常亮”等灯效重新开启，不需要重置固件或重新插线。** 仅调整亮度或速度时会保留关灯状态。需要查看实体操作后的状态时可点“读取键盘”。普通灯光或设备功能同步错误不再阻止独立的键位保存；连接丢失仍会停止写入。

v1.1.2 修复实时队列把浏览器原生定时器作为普通对象方法调用，导致 `Illegal invocation`、写入尚未开始便中断的问题。实时发送、自动保存与取消定时任务均使用保留正确调用上下文的包装函数。新增检查在旧代码上重现同一错误，修复后覆盖不点击应用的完整自动发送与保存流程。实物验证步骤见 [docs/VERIFY.md](docs/VERIFY.md)。

灯光、模式、计时时长与休眠设置调整后实时发送，连续拖动会合并为最新值，停止操作约 1 秒后发送保存指令。状态会显示“正在实时应用”“已生效”“已实时同步并保存”；关闭或拔线前请等到保存完成，也可通过“使用帮助 → 退出软件”完成保存并退出。键位仍需明确点击“应用键位”。

旧版要求回读亮度与请求值完全一致，但 QMK 会进行整数缩放。新版本对亮度允许最多 3/255 的向下取整差，采用实际回读值作为基准；灯效、速度和颜色仍严格校验。只发送发生变化的参数，避免切灯效时反复换算亮度。普通参数校验错误不会直接断开可响应的键盘；错误会显示在界面并保留诊断记录。

连接时读取设备当前灯光和功能；离线预览不会在连接瞬间自动写入。连接后的手动调整和匹配方案载入才会实时写入。选择一个基础灯效会同时回到 SYNC 模式。

## 本版集成的功能

| 功能 | 支持内容 |
| --- | --- |
| 前灯带效果 | 21 种通用效果 + 14 种 CU 灯带效果，以及关闭；亮度、速度、色相和饱和度 |
| CU 专属效果 | 波浪、往返扫描、脉冲、闪电、迪斯科、双向扫描、星光闪烁、频闪、极光、霓虹、激光、心跳、烟花、彩虹追逐 |
| 前灯带双向开关 | 软件联动的专用 F24 触发键；恢复上次灯效和模式，需 Windows 直接连接并保持窗口运行 |
| 灯带模式 | SYNC 同步灯效、MUSIC 音乐律动、SPEED 打字速度、POMODORO 番茄钟 |
| 番茄钟设置 | 专注 5–35 分钟，每档 5 分钟；休息 5 或 10 分钟，与 CU JSON 菜单一致 |
| 无线休眠 | 永不休眠、15/30 秒、1/2/5/10/15/20/25/30 分钟；USB 有线模式忽略休眠 |
| 专用快捷键 | CU 固件的 24 项可分配功能，包括音乐校准、仪表盘、番茄钟控制、RGB 协议切换、游戏模式、充电指示灯、系统切换、Mac 功能 |
| 键位与图层 | 67 个实体键、实际读取图层数；基本键、功能键、媒体键、图层、灯光与专属键码 |
| 配置与恢复 | 导入 / 导出 JSON、本机方案、写入前自动备份、逐项回读校验、失败后尝试恢复 |
| 按键测试 | 检测当前窗口收到的 Windows 按键事件 |

部分特效会忽略颜色或速度参数。前灯带动画是屏幕示意，固件的实际色彩、节奏和方向可能不同。原厂固件若不提供 CU 扩展参数，将进入兼容模式，不开放这些扩展设置。保留 v1.0.1 对 32 / 64 字节 HID 报告及非零报告编号的修复。

### 音乐、打字速度与番茄钟

- 音乐由**键盘内置麦克风**采集；软件不会采集电脑声音，也没有读取音量数据。
- 在“设备功能”查看专用键当前所在的图层 / 行 / 列。“选择按键”会带你到按键库；选中键帽，再选择功能，应用后通过实体键触发。
- 音乐校准通过“音乐校准”专用键触发；按固件说明在安静环境操作。
- 番茄钟模式和时长可在软件中设置；“番茄钟启动 / 暂停”对应 VIA 定义的 PMD_TG，具体阶段操作以固件行为为准。
- WPM 和番茄钟实时进度由键盘计算并显示在灯带上，软件没有对应的实时遥测接口。
- BAT 电量显示只供无线使用；本软件的 USB 菜单不提供电量模式选择或虚假的电量百分比。若设备读取到 BAT 模式，请先选 SYNC 或其他支持模式再修改设备功能。

### RGB 软件与范围

VIA、OpenRGB、SignalRGB 是固件支持的不同控制协议，默认 Fn + Y 切换时分别使用红、绿、蓝色反馈。本软件使用 VIA 配置通道。OpenRGB / SignalRGB 的插件及使用说明见固件项目；本版没有捆绑这些软件或接管它们的实时 RGB 流。

仓库的 AI Agent 功能针对标准版 NUT65，CU 不提供该功能，因此没有添加为 CU 可用硬件功能。此工具不刷固件、不擦除 EEPROM，不提供逐灯珠绘图、动画上传或状态指示灯颜色逐个编辑，也不读写设备宏与旋钮数据。

图层 0/1 通常用于 Windows，2/3 用于 Mac，具体由固件决定。更改 Fn 时应保留进入功能层的方式。组合键可输入 `LCTL(KC_C)`、`LSFT(KC_A)`、`LALT(KC_TAB)` 等单修饰键表达式；未知键码可用 `0x1234` 保存。

## 备份与方案

- `data/profiles.json`：本机保存的方案。
- `data/strip-shortcut.json`：前灯带软件联动的启用偏好与恢复灯效、模式。保存于软件目录，迁移时与其他 data 文件一起复制。
- `data/backups/`：每次连接的首次实时修改，以及每次改键前生成的设备键位、灯光和扩展设置快照。
- 恢复时使用 **配置方案 → 导入 JSON**。确认载入后，匹配固件的灯光与设备功能实时同步；键位通过 **应用键位** 保存。
- 方案格式 v2 记录固件标记，避免第三方与原厂灯效编号混用。导出仅包含本工具管理的配置，不是完整固件镜像。
- 单独 HTML 预览的方案与恢复快照保存在浏览器本地存储；通过 EXE 的任一连接方式操作均写入程序旁的数据目录。
- 连接记录在 `data/connection.log`；连接失败时可导出诊断。日志不采集日常键盘输入。
- 可用 **使用帮助 → 退出软件** 立即结束本机服务；仅关闭窗口后，服务在数分钟无活动后退出。

## 源码与构建

- `src/Program.cs`：Windows 启动器、本机界面服务、通道与指令校验、备份和方案。
- `src/HidTransport.cs`：Windows HID 连接与按描述符分帧。
- `src/StripShortcut.cs`：专用 F24 注册、无按住重复的通知、单窗口接收与偏好；不安装通用键盘钩子。
- `ui/core.js`：键码、CU 参数、灯带示意、VIA 事务与恢复。
- `ui/app.js`、`index.html`、`style.css`：交互与视觉。
- `docs/PROTOCOL.md`：协议说明。`docs/reference/nut65-cu-v37.json`：参考定义快照。
- `docs/VERIFY.md`、`docs/SHORTCUT-AND-EFFECTS.md`：v1.1.5 软件开关、灯效对照、实时同步与故障记录的验证方法。
- `docs/THIRD-PARTY-NOTICES.md`：第三方来源与 MIT 许可。
- `tests/`：模拟设备、界面状态和 Windows 边界检查。
- `tests/make-preview.js`：生成可用 Edge 打开的单文件预览，实际连接推荐使用 EXE。

PowerShell 构建（仅使用 Windows 自带 C# 编译器）：

```powershell
.\test.ps1
.\build.ps1
python scripts/package.py
```

测试需要 Node.js 20 或更新版本及 Python 3.11 或更新版本，无需 npm / pip 第三方依赖；不在 PATH 时可通过 test.ps1 的 NodeCommand、PythonCommand 参数指定。构建和发布资产输出到 `dist/`，包括便携 ZIP、单文件 EXE、源码 ZIP 和 `SHA256SUMS.txt`；测试产物输出到 `artifacts/`。便携包只含运行程序、入门说明和许可文件，源码包使用 scripts/source-files.txt 允许列表，两者均不含个人配置、备份或连接日志。图标已内置；可选的 tests/make-icon.js 需单独安装开发依赖 sharp，运行软件无需此依赖。执行 `node tests/make-preview.js` 可生成单文件预览。GitHub Actions 会执行测试、构建和打包；维护者发布步骤见 [PUBLISH.md](docs/PUBLISH.md)。
