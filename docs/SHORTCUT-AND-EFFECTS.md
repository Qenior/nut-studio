# v1.1.5 前灯带开关与灯效对照

## 配置真正双向的前灯带软件开关

1. 退出旧版，解压并运行 v1.1.5，选择“Windows 直接连接”，确认已识别 CU 固件，RGB 控制协议为 VIA。
2. 在“键位设置”选择需要修改的图层和按键。例如要使用 Fn + 某键，选择对应 Fn 图层；保留进入该图层的 Fn 键。
3. 在“灯光快捷键”选择 **前灯带开 / 关（软件联动）**，点击 **应用键位 → 应用并保存**。
4. 选择喜欢的灯效并等待自动保存。按刚才分配的实体键：第一次关闭前灯带，第二次恢复关闭前的灯效和模式。

原来的“灯光开关”现在明确标为“全局 RGB 开关（固件）”。固件 `RL_OFF / CUSTOM(16)` 依旧是单向关闭。这两个键都不被软件悄悄替换，需要手动重新选择新选项。

软件联动通过专用 **F24** 通知，再用已有 VIA 通道完成开关。关闭时选择 CU 的灯带专用关闭状态 22，并回到 SYNC；恢复时恢复上次灯效、模式，亮度和颜色保持当前值。可恢复的模式为 SYNC、MUSIC、SPEED 和 POMODORO；USB 不设置 BAT 模式。首次启动时如果键盘已经关闭、且尚无保存的恢复偏好，将使用常亮。

**需要 NUT Studio 窗口运行，可以最小化。** 关闭窗口、退出软件、断开 USB 或切到独立 HTML/WebHID 方式后，这项软件联动停止。只修改 VIA 键位不能改写固件里的按键处理；若要求软件完全退出、无线连接时也实现相同的独立前灯带双向逻辑，需要固件提供相应实现及源码。此版没有刷写或修改固件。

启用后 F24 被专用于此功能，不再提供给其他程序；其他键盘发送 F24 也会触发，这是 Windows 系统热键的范围。F24 被其他程序占用时会在写入键位前提示。取消时，将所有“前灯带开 / 关（软件联动）”改为其他键并应用，软件会释放 F24。按键测试不应再用 F24 是否出现在日志中判断成功，请观察前灯带。

## 验证开关

- 连续按下、松开五次，应按关闭/开启交替变化；按住不应不断闪烁。快速按两次最终应恢复开启。
- 选择 MUSIC 后关闭，再开启，应恢复 MUSIC。该模式的声音仍来自键盘内置麦克风。
- 关灯后测试 Caps Lock 或按住 Fn 查看指示灯，确认前灯带关闭没有代替状态指示灯的开关。
- 最小化软件后重复测试。再退出软件，确认不再发生软件联动；重新启动并直接连接后应恢复联动。
- 停止操作约 1 秒，状态应为“已实时同步并保存”。正常日志中开关只修改灯效 ID 2 和必要的灯带模式 ID 4；不会把颜色、亮度归零。

## 游戏模式是什么

CU 的 `customKeycodes[15]` 定义为 `Game Mode / KC_GME`，软件写入 `CUSTOM(15)`。公开 VIA 定义只给出了这个名称，手册没有说明其按下行为，因此目前无法确认它是保留占位还是已实现的功能。

它不是软件提供的 Windows 游戏模式设置，也不能确认能提高回报率、降低输入延迟或锁住 Win 键。Win 键锁定在固件手册中是独立功能。界面已标明“游戏模式（固件未说明）”。
