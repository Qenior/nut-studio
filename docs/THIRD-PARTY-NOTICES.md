# Third-party reference

NUT Studio adapts the CU effect IDs, custom menu definitions and custom-key
semantics from **weika-nut65-firmware**, by **打包还是带走 / packOrTake**.

- Project: https://gitee.com/packOrTake/weika-nut65-firmware
- Reference: CU V37, master commit `8427691`, retrieved 2026-10-22.
- Definition: `cu/NUT65 CU.json`; snapshot in `reference/nut65-cu-v37.json`.
- No firmware binaries, SignalRGB plugin or AI Agent executable are bundled.
- Our interface and host adapter are independently implemented. The preview
  illustrates effects and does not reproduce firmware rendering code.
