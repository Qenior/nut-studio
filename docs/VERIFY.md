# NUT Studio v1.1.5 实物验证

本版修复资源生命周期和诊断隐私。保留原有“前灯带开 / 关（软件联动）”及灯效映射；按 [SHORTCUT-AND-EFFECTS.md](SHORTCUT-AND-EFFECTS.md) 验证连续按两次能关闭、恢复，并检查状态指示灯。需要 Windows 直接连接和窗口运行（可最小化）。旧固件键不会自动换成新功能。

## 1. 确认启动的是新版

1. 在旧版选择 **使用帮助 → 退出软件**。关闭 VIA、OpenRGB、SignalRGB 等其他控制软件。
2. 将 ZIP 解压到一个新文件夹，运行其中的 `NUT-Studio.exe`，确认左下角显示 **v1.1.5**。不要在压缩包内直接运行。
3. USB 连接并切到有线模式。第三方 CU 固件使用 VIA RGB 协议：默认 **Fn + Y** 循环切换，红色反馈表示 VIA；若已改键，使用对应专用键。
4. 选择 **连接键盘 → Windows 直接连接**，等待设备配置读完。记录当前灯效、亮度、模式与番茄钟时长，方便恢复；首次实际修改前还会自动生成 `data/backups/` 快照。

## 2. 重点验证：实体关灯后恢复与改键

1. 用你原来使用的实体组合键关闭灯带，再点击软件顶部的 **读取键盘**。应正常完成读取；灯光页显示前灯带关闭状态，亮度等控件仍可操作，不再报“不支持此固件的灯效编号”。
2. 选择 **常亮** 或 **灯带 · 波浪**。实物应重新亮起，停止操作约 1–2 秒后显示“已实时同步并保存”。无需点击应用，也不需要重新插线。
3. 再次用实体组合键关灯，这次直接点击软件里刚才选中的灯效，不先读取。即使屏幕上还选中旧灯效，软件也应根据实际回读值重新写入，恢复亮灯。
4. 再次关灯，点击“读取键盘”，任选一个不影响 Fn 操作的普通键临时改为 **F13**，通过 **应用键位 → 应用并保存** 保存。用“按键测试”确认实体键收到 F13，之后恢复原键位。改键期间灯带应保持关闭，且不会因关灯值 22 阻止键位写入。
5. 灯带仍关闭时退出并重启软件，再连接。应能正常读取关闭状态；随后选择灯效应再次恢复亮灯。

关灯状态下只调整亮度或速度会保留关灯，请选择一个灯效重新开启。当前实体快捷键操作的状态在“读取键盘”或下一次实时调整后刷新。

## 3. 验证灯带实时变化

| 操作 | 通过条件 |
| --- | --- |
| 在“灯光效果”选择“常亮”，调整亮度至约 30%，将颜色改为蓝色 | 实物前灯带变化；无须点击“应用键位”；无 `Illegal invocation` 提示 |
| 将亮度拖至约 60%，再连续拖动 2–3 秒 | 拖动期间实物亮度持续变化，连接保持在线；停止后以最后位置为准 |
| 选择“灯带 · 波浪”（编号 23），改变速度 | 实物出现波浪动画；模式自动回到 SYNC；速度变化以固件实际表现为准 |
| 停止操作约 1–2 秒 | 状态从“正在实时应用…”或“已生效 · 等待自动保存”变为“已实时同步并保存” |

先用常亮验证颜色，因为部分动态灯效使用固定或随机颜色。亮度回读最多可比请求低 3/255，这是固件整数换算，不应触发回滚、断连或连续报错。

## 4. 验证设备功能与回读

1. 在“设备功能”把专注时长改为与当前不同的值，例如 **25 → 30 分钟**，等待“已实时同步并保存”。不需要启动番茄钟，也不需要点击应用。
2. 点击顶部 **读取键盘**。专注时长应仍为刚才的值；灯效、速度、颜色也应保留，亮度允许上述小幅取整差。
3. 继续调整一次灯效并等待保存，确认“读取键盘”之后实时控制仍然正常。

USB 有线模式会忽略无线休眠设置，不能通过“有线连接时是否睡眠”判断该设置写入是否成功。

## 5. 验证重新连接与掉电保存

1. 等待“已实时同步并保存”，选择 **使用帮助 → 退出软件**，重新启动 v1.1.5 并连接。读取的灯效和时长应保持。
2. 若要验证真正掉电保存：保存完成后退出软件、拔掉 USB，并通过键盘电源开关关闭电池供电；再恢复有线连接、启动软件读取。灯效与时长应保持。请按键盘实际供电方式操作，不需要拆机。

这款键盘带电池，单独拔掉 USB 不一定完全断电。重新启动软件或 USB 重连通过，只能证明重新连接后仍保留设置，不能单独证明 EEPROM 掉电保存通过。

## 6. 如果仍不正常

保留新版程序同目录的 **`data/connection.log`**，记录操作时间、选择的灯效和参数、界面状态、实物表现，以及报错原文或截图。不要使用旧版文件夹里的日志。连接失败弹窗也提供“导出连接诊断”。

Windows 直接连接的正常配置日志会包含下列指令前缀；一次灯效调整可能穿插多条回读，不要求每行连续：

| 指令前缀 | 含义 |
| --- | --- |
| `07-03-...` | 发送灯光设置 |
| `08-03-...` | 读取、校验灯光 |
| `08-03-02-16-...` | CU 实体关灯值 22 的回读；本版支持该状态 |
| `09-03-...` | 保存灯光 |
| `07-00-...` / `08-00-...` / `09-00-...` | CU 功能的设置 / 读取 / 保存 |

首次实际修改后，`data/backups/` 应新增一个修改前快照。同一连接后续调整通常复用该备份；参数本身没有变化时，也不会重复发 SET 或 SAVE。

- 再次出现“不支持此固件的灯效编号”：先确认版本为 v1.1.5，保留带编号的完整错误与对应 `08-03-02` 回读记录。
- 仍出现 `Illegal invocation`：确认界面版本为 v1.1.5，并保存错误原文与操作时间。
- 有灯光 SET、回读和 SAVE，界面显示已保存，但实物不变：记录灯带模式与 RGB 控制协议，优先检查 VIA / SYNC 状态及固件表现。
- 出现回读校验、保存或 USB 错误：保留出错时段完整日志，以便区分固件响应、参数校验与实际通信中断。

## 7. 资源与隐私回归

1. 在灯光页与改键页之间切换 20 次，暂停 / 恢复预览，最小化再恢复；动态灯效应流畅恢复，选中的灯效、搜索和颜色保持正确。启用系统“减少动态效果”时，保留静态预览。
2. Windows 直接连接以及浏览器 USB 分别完成若干次连接、断开、拔线、重连。等待中的操作应报错并停止，重连后前灯带、改键及即时应用仍可使用。
3. 有未完成读取、实时调节或快捷键轮询时退出，再次启动。旧窗口不得重新连接或继续写入。正常退出后可重新启用 F24 软件灯带开关，不应残留注册。
4. 同一负载下分开观察 NUT-Studio.exe 与 Edge 渲染进程的内存和句柄：先预热，再连续进行 20 轮相同操作，记录每轮数值及空闲后的稳定范围。单次峰值或尚未 GC 的工作集不能独自证明泄漏或修复收益。
5. 导出连接诊断，检查不含个人用户名、绝对目录、会话 token、邮箱或唯一 HID 路径。旧日志也应在导出时脱敏。保留参数和指令信息供排错，不要公开整个 data 文件夹。
6. 对比升级前后的个人备份数量与 SHA256；已有备份必须保留。新版首次修改生成的新备份应能在配置页导入。

自动检查使用模拟设备、浏览器定时器模型和独立原生边界测试；没有进行本版的实物 HID/F24 验收，不宣称以上项目已经通过。
