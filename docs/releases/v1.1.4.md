# NUT Studio v1.1.4

首次公开发布，适用于 Windows 11 x64 和 WEIKAV NUT65 CU，主要适配 packOrTake CU V37 固件。

## 功能

- 67 键可视化改键、图层和 CU 专用键码。
- 前灯带灯效、颜色、亮度、速度实时调整。
- WPM、番茄钟、仪表盘等固件扩展设置。
- 本机方案、JSON 导入导出、修改前快照及回读校验。
- Windows 直接 HID 连接，并保留 WebHID 备用方式。

## 本版本修复

- 正确接受实体快捷键关闭灯带后的 22 号状态。
- 新增“前灯带开 / 关（软件联动）”，恢复关闭前的灯效与模式。
- 调整 CU 灯效名称与屏幕示意，区分前灯带和逐键背光。
- 保留 32 / 64 字节 HID 报告和非零报告编号的处理。

## 下载与使用

下载 **NUT-Studio-Win11-v1.1.4.zip**，解压后运行 **NUT-Studio.exe**。也可以使用单文件 **NUT-Studio-v1.1.4.exe**。**SHA256SUMS.txt** 用于核对下载文件。

软件使用系统 .NET Framework 4.8 和 Edge，无需另装 USB 驱动。当前 EXE 未进行代码签名。

前灯带软件开关使用 F24，需 Windows 直接连接且软件窗口保持运行；可以最小化。灯光和设备功能实时应用；键位修改需点击“应用键位”。
