# NUT Studio v1.1.5

本版针对内存分配、设备断连和退出清理、灯光预览及诊断隐私进行修复。

- 键码目录使用有上限的缓存及索引，保留兼容 / 新版编码、CU 功能和前灯带软件开关。
- WebHID 在断连、超时、发送失败和关闭时移除监听、清除计时器并拒绝未完成请求；不支持指令的探测仍可恢复。
- 快捷键服务释放时唤醒等待者并停止线程，避免保留内核等待句柄；退出竞争不会重建连接和旧轮询。
- 灯光预览复用 80 个 LED 和未改变的灯效卡片，仅在灯光页可见、未暂停且未要求减少动画时调度。
- 按键测试只保留物理 code；诊断写入及历史导出会脱敏；配置、会话及本机请求增加大小、时限和并发边界。
- 便携包、独立 EXE 和源码包均通过明确允许列表生成并进行隐私检查。可选图标脚本使用开发依赖 Sharp，运行软件无需 Node、Python 或 Sharp。

下载 `NUT-Studio-Win11-v1.1.5.zip` 后解压到新文件夹运行；也可使用 `NUT-Studio-v1.1.5.exe`。`NUT-Studio-Source-v1.1.5.zip` 是源码，校验值见 `SHA256SUMS.txt`。

升级前在旧版选择“使用帮助 → 退出软件”。保留旧版的 `data/backups/`、`profiles.json` 和 `strip-shortcut.json`；需要迁移时先复制这些配置到新版的 data 目录。不要将 session.json、日志或备份放进公开发布包。

v1.1.4 的前灯带、改键、实时应用曾获得用户正常使用反馈。v1.1.5 的自动化协议、生命周期及原生边界检查不能替代真机验收。本版尚未完成真实键盘 HID、F24 软件快捷键及长期内存 / 句柄测量验收。按 [VERIFY.md](https://github.com/Qenior/nut-studio/blob/v1.1.5/docs/VERIFY.md) 验证灯带开关、即时应用、改键、拔插及退出行为后再确认硬件通过。
